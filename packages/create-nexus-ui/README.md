# create-nexus-ui

Starts a FiveM resource with [Nexus UI](https://nexusstudios-ui.vercel.app), a UI framework made for FiveM.

```
npm create nexus-ui my_shop
cd my_shop
npm install
npm run dev
```

It runs `nexus create my_shop` from the newest `@nexusstudios/ui`. The folder it makes is a complete
resource: one screen, one call with its server handler, a browser mock and a locale.

Documentation and a playground: https://nexusstudios-ui.vercel.app

Source: https://github.com/NexusStudiosCfx/nexus-ui
