Nexus UI is a UI framework for FiveM resources. You write components in `.nexus` files and
declare every message between the page and Lua once. What you get is a page that costs nothing
while it is closed, and a server that only ever sees input it has already validated.

<Code code={`${SITE.install}\ncd my_shop\nnpm install\nnpm run dev`} lang="sh" frame="none" />

`npm run dev` opens the UI in a browser, with a mock in place of the game. It needs Node.js 20
or newer, and the resource needs `lua54 'yes'`.
